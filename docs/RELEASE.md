# Release

## Desktop Artifacts

ZuraAI uses `electron-builder` for production packaging.

```bash
bun run build
```

Electron Builder is configured with `npmRebuild: false` so packaging does not require local Visual Studio Build Tools just to rebuild optional native dependencies. Native runtime dependencies must be supplied as installable/prebuilt packages.

The build writes release artifacts to `release/`:

- `ZuraAI-Setup-{version}.exe` - Windows NSIS wizard installer
- `ZuraAI-Portable-{version}-x64.exe` - Windows portable executable used by the package-manager launcher
- `checksums.txt` - SHA-256 checksums for release artifacts

`checksums.txt` is generated by `scripts/generate-release-checksums.mjs` after `electron-builder` finishes. Run this manually if artifacts are added after the build:

```bash
bun run release:checksums
```

## npm Package

The npm package in `packages/zuraai` is currently published as `zuraai@0.0.0`, a README-only placeholder that points users to `https://zuraai.in`.

`zura` is not available on npm; use `zuraai`.

For placeholder releases:

```bash
cd packages/zuraai
npm pack --dry-run --json
npm publish --access public
```

If npm requires a publish token:

```powershell
$env:NPM_TOKEN="paste_token_here"
npm publish --access public --//registry.npmjs.org/:_authToken=$env:NPM_TOKEN
Remove-Item Env:\NPM_TOKEN
```

Verify the published package:

```bash
npm view zuraai name version homepage description --json
```

## Future Package-Manager Launcher

When `packages/zuraai` becomes a real launcher, it should remain a small package, not the desktop app binary. Users should then be able to run:

```bash
bunx zuraai
npx zuraai
```

The launcher should resolve a GitHub release tag, download the matching desktop artifact, verify it against `checksums.txt`, cache it under the user's local cache directory, and launch it.

For launcher package version `0.0.6`, the GitHub release must have tag `v0.0.6` and include:

- `ZuraAI-Portable-0.0.6-x64.exe`
- `ZuraAI-Setup-0.0.6.exe`
- `checksums.txt`

Launcher publish order:

1. Update the root app version and `packages/zuraai/package.json` version together.
2. Run `bun run build`.
3. Upload the installer, portable executable, update metadata, blockmaps, and `checksums.txt` to the GitHub release.
4. Run `cd packages/zuraai && npm pack --dry-run --json` and confirm the tarball contains the intended launcher files.
5. Publish `packages/zuraai` to npm after the GitHub release assets are available.
