# zuraai

Install and launch the **ZuraAI desktop app** from npm.

```sh
zuraai
zuraai open
zuraai install
zuraai chat "summarize this repo"
```

When the desktop app is missing, the launcher downloads the matching GitHub Release, verifies its SHA-256 checksum, and starts the visible Windows installer. On macOS it installs the verified universal app under `~/Applications`. Later commands open the installed app immediately through its registered local protocol.

Works on macOS and Windows.

Site: [zuraai.in](https://zuraai.in)
